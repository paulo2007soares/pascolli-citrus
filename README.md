# Pascolli Citrus — Website Profissional & Dinâmico

Este repositório contém a aplicação web completa e pronta para produção do site **Pascolli Citrus**.

## 🚀 Funcionalidades
- **Efeitos 3D / Parallax Interativos:** Card em 3D responsivo ao movimento do mouse e frutas flutuantes.
- **Glassmorphism Design:** Design moderno Dark-Mode com efeito de iluminação suave do cursor.
- **Carrinho de Compras Interativo:** Adicione produtos por tamanho (5L, 2L, 500ml) e visualize o total em tempo real.
- **Checkout Integrado ao WhatsApp:** Envio do pedido formatado diretamente para a conversa da empresa.
- **Animações ao Rolar (AOS):** Transições suaves à medida que o usuário navega na página.

## 📁 Estrutura de Arquivos
- `index.html`: Estrutura semântica HTML5.
- `style.css`: Estilização completa, variáveis CSS, animações 3D e responsividade.
- `script.js`: Lógica de renderização de produtos, interatividade e integração de carrinho/WhatsApp.
- `schema.sql`: Script MySQL para criação do banco de dados e tabela de produtos/pedidos.

## 🛠️ Como Hospedar
1. Extraia o arquivo `.zip` na sua hospedagem (Hostinger, Vercel, Netlify ou GitHub Pages).
2. O site é 100% estático e funcional para o cliente no front-end!
3. Caso queira conectar a um banco backend no futuro, utilize o arquivo `schema.sql` fornecido.
